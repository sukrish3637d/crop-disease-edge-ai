# Crop Disease Edge AI

A smartphone-oriented rice leaf disease classifier for smallholder farmers, being built to be honest about its own uncertainty, tested under field-style conditions, and small enough to run offline.

**Status:** Work in progress. Phase 1 (data understanding, de-duplication and train/val/test split) is done; no model has been trained yet.

## Data

- **Dataset:** Paddy Doctor, Kaggle competition subset (10,407 labeled images, 10 classes), collected from paddy fields in Tamil Nadu, India.
- **Citation:** Petchiammal A, Briskline Kiruba S, Murugan D, Arjunan P. "Paddy Doctor: A Visual Image Dataset for Automated Paddy Disease Classification and Benchmarking". CODS-COMAD 2023. arXiv:2205.11108. IEEE DataPort DOI: 10.21227/hz4v-af08.
- **Download:** Accept the competition rules and download the data from https://www.kaggle.com/c/paddy-disease-classification/data, then unzip it so that these exist:
  - `data/raw/paddy-disease-classification/train_images/` (one sub-folder per class)
  - `data/raw/paddy-disease-classification/train.csv`
- The images are not included in this repository and are not redistributed.
- **Licence note:** The dataset authors state it is released open source for community use; the licence terms of the Kaggle copy have not been verified here, so check the competition rules before reusing the data.

## Reproduce

Run these commands from the repository root.

```bash
# Install dependencies
uv sync

# Hash images and write data/processed/dedup_manifest.csv
uv run python src/data_prep/dedup.py

# Write data/processed/split.csv
uv run python src/data_prep/split.py

# Run the tests
uv run pytest
```

The files in `data/processed/` are generated by these scripts and are not committed.

## What the Data Analysis Found So Far

- 10,407 images, no corrupted files.
- 206 images (1.98%) removed: 202 exact duplicates plus 4 images that form 2 pairs carrying two different disease labels.
- Class imbalance of about 5.2:1.
- Rice variety is strongly confounded with disease label (about 98% of healthy training leaves come from one variety, ADT45).
- To measure this, all images of the Ponni variety (649) are held out as a separate stress set.

## Known Limitations So Far

- The data comes from one region.
- The variety confound described above.
- Photos from the same field visit that are not pixel-identical may still appear in both train and test, which has not been audited yet.
- This is a prototype, not a certified diagnostic tool.
